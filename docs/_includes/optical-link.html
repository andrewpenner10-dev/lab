Illustration: light ON = 1, light OFF = 0. A photodiode turns the received light into an electrical signal. Circuit polarity can reverse this mapping. The waves are symbolic; the bit rate changes the light’s intensity, not its speed through space.

Try a single bit

A bit is a state held for a time

At 200,000 bit/s, each bit gets 5 µs. A 1 followed by another 1 keeps the laser on for 10 µs. Only a change from 1 to 0, or 0 to 1, requires a switch.

So 200 kb/s does not mean 200,000 complete flashes per second. An alternating 1010… pattern makes 100,000 full ON/OFF cycles per second.

The start bit begins the frame. Eight data bits follow, least-significant bit first, then a stop bit. This example carries byte 0x4B.

Agree on the rate

Both ends use the same nominal bit rate and frame format. Their clocks run independently; there is no separate clock wire across the light link.

Find the start

UART normally idles at logic 1. The transition to a start bit of 0 gives the receiver a timing reference. It samples near each bit’s center and aligns again at the next frame.

Keep timing close

Too much clock mismatch, jitter, or a slow detector can move a sample into the wrong bit. The transmitter, laser driver, and receiver all need to resolve a 5 µs interval at 200 kb/s.

Bytes travel in packets

A byte frame sets the timing. A packet groups several bytes into a message the receiver can identify and check.

Conceptual packet layout, not a byte-for-byte specification of this lab’s protocol. Each packet byte is sent inside its own UART frame. Packet markers identify message boundaries; start bits establish byte timing. A CRC helps detect corruption, but does not correct it or guarantee delivery.

With 8N1 framing, 8 data bits use 10 bit intervals. At 200 kb/s, that allows at most 160 kb/s of byte data before packet headers, checks, and gaps. The lab measured about 18.7 kb/s of useful payload including those costs.
