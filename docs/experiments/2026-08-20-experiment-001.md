## Goal

Build a system that allows two computers to communicate with each other using a laser beam.

## Starting Point

I have no experience building optical communication systems. I'm starting from the beginning and learning by building.

## First Prototype

Computer A → microcontroller → laser → photodetector → microcontroller → Computer B

First milestone: transmit "HELLO SPACE" from one computer to another through light.
